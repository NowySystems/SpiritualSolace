## Matching Logic

Each grant or funding opportunity should be matched to:

1. Mission fit
2. Fund class fit
3. Program fit
4. Geography fit
5. Deadline risk
6. Eligibility confidence
7. Application burden
8. Match requirement
9. Recommended action
