# Notes Index

Purpose: Track owner voice notes, meeting notes, strategy notes, and historical context without polluting current source-of-truth docs.

## Rules

- SAVE_STATE.md and ROADMAP.md remain current truth.
- docs/notes entries are archival/contextual.
- Speech notes may include stale phase references.
- Each note must include status and actionable carry-forward.
- Do not update current phase from a voice note without explicit review.


## Timestamp Policy

All owner voice notes, roadmap-impacting notes, helper/staff plans, and phase updates should include a timestamp in `YYYY-MM-DD HH:MM UTC` format when possible. Notes without exact time should use `YYYY-MM-DD — time not recorded`. Timestamps are used for sequencing only and do not override `SAVE_STATE.md` or `ROADMAP.md`.

- Future phase updates and major PR summaries should include timestamp metadata when practical.
