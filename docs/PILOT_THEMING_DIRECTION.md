# ChurchWork Pilot Theme Direction

Date: 2026-07-01

## Theme posture

ChurchWork should feel calm, secure, human, and facility-safe.

Avoid looking like:

- A medical chart.
- A church CRM.
- A generic dark SaaS dashboard.
- A fundraising/event product.
- A chat app.

ChurchWork should feel like:

- Infrastructure for compassion.
- A secure care coordination workspace.
- Warm enough for families and churches.
- Professional enough for facilities.

## Pilot palette

Use one stable pilot palette unless there is a strong reason to change it later.

- Deep Trust Green: `#173B2D`
- Warm Cream: `#F7F3EA`
- Soft Sage: `#8AA363`
- Charcoal Blue: `#102B3A`
- Muted Gold: `#DDB66C`
- Border Linen: `#D8D0C0`
- White: `#FFFFFF`

## Usage

Deep Trust Green:

- Primary buttons.
- Secure workspace headers.
- Role/path emphasis.

Warm Cream:

- Page background.
- Friendly surfaces.
- Requester-facing calm areas.

Soft Sage:

- Success states.
- Secondary accents.
- Spiritual-care highlights.

Charcoal Blue:

- Serious text.
- Owner/admin/security surfaces.
- High-trust panels.

Muted Gold:

- Warnings.
- Pilot/demo notices.
- Acknowledgment callouts.

Border Linen:

- Cards.
- Separators.
- Low-noise UI structure.

## Product language

Use:

- Care Team Workspace.
- Requester Path.
- Facility Path.
- Partner Path.
- Shared Care Timeline.
- Spiritual-care request.
- Non-medical coordination note.
- Partner-safe request context.

Avoid:

- Chat.
- Message thread.
- Medical note.
- Patient chart.
- Auto-route.
- Auto-match.
- Diagnosis.
- Case file.
- Healthcare record.

## Tone

Short, calm, direct.

Examples:

- Request spiritual care.
- Grandview will review this request.
- Hope Church will only see partner-safe request context.
- Do not enter medical information.
- This is not for emergencies.

## Pilot polish rule

Do not change the frozen demo unless something is broken.

Apply this theme direction first to new live-pilot surfaces:

- Sign in.
- Requester structured intake.
- Facility queue.
- Partner workspace.
- Shared timeline.
- Policy acknowledgment pages.
