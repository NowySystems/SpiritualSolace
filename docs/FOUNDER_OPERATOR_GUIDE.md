# Founder / Operator Guide

**Timestamp:** 2026-05-20 — Founder / Operator Growth + Command Dashboard Direction

## Role Model (Locked)

- **Owner / Lead:** user
- **Second-in-command:** ChatGPT
- **Builder:** Codex or better coding tool if needed
- **Validators:** GitHub Actions, Playwright, helper scripts
- **Staff/helpers:** read-only report generators
- **Advisor/helper layer:** recommends next moves but never writes/decides alone

## Founder Growth Direction

The user is becoming an AI-assisted founder, product lead, and systems operator.

### Focus Areas

- acceptance criteria
- file responsibility map
- product discipline
- technical triage
- design checklist
- market/competitor judgment
- reusable operating systems

## Core Principle (Locked)

Do not just learn to code. Learn to direct an AI-assisted product team without letting it build garbage.

## Operating Notes

- Keep decisions owner-controlled and human-reviewed.
- Keep helper/agent outputs read-only and recommendation-only.
- Keep roadmap phase transitions explicit and documented.
- Preserve retrievable context across products through save-state, reports, and decision logs.
