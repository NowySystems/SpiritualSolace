# Service Area Validation (CRCF 3.2)

CRCF 3.2 adds structured service-area validation for Tennessee and Upper Cumberland relevance.

## Output fields

- `serviceAreaStatus`
- `serviceAreaSummary`
- `upperCumberlandEligible`
- `tennesseeEligible`
- `localRestrictionRisk`
- `staffVerificationRequired`
- `reason`

## Status values

- `upper_cumberland_confirmed`
- `tennessee_statewide`
- `rural_tennessee_likely`
- `national_tennessee_eligible`
- `major_city_limited`
- `unclear_staff_verify`
- `likely_not_applicable`

## Governance posture

- Validation is advisory and read-only.
- Human review is required before any external action.
- Service-area classification never submits, persists, or sends external outreach.
